About This Project

InsiderDetection helps security teams spot risky insider behavior early by combining user behavior analytics, anomaly detection, and risk scoring.

What We Track

  • Identity Signals: Login timing, geo mismatch, and repeated failed sign-ins.
  • Data Access: Sensitive file reads, bulk copy, and unusual delete patterns.
  • Network Footprint: Suspicious outbound transfer and unknown domain contact.
  • Device Behavior: Application usage spikes and automation-like activity.

How It Works

  • Step 1: Collect behavioral logs from users, endpoints, and network activity.
  • Step 2: Build a normal baseline per user/team using ML models.
  • Step 3: Score anomalies by severity and context.
  • Step 4: Trigger real-time alerts for high-risk incidents.
  • Step 5: Support investigation via dashboard and detection pages.
